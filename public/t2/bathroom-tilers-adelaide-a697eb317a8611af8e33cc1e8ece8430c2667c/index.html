Where waterproofing changes the decision

Tiles and grout do not make a shower waterproof, so the tiler discussion should include membrane boundaries, penetrations, thresholds, cure sequencing and how the handover from waterproofing to tiling will be recorded. A quote that jumps straight to a square metre rate can miss preparation, waterproofing and sequencing.

For a leak or failed shower finish, regrouting may suit a maintenance issue, but it should not be treated as a universal leak repair. A diagnosis-led scope separates sealant, plumbing, substrate movement and membrane assumptions before work is reduced to a surface repair. Written inclusions matter more than verbal confidence.

Ask the provider to state the product system used, the preparation required by that system and the point at which tiling can begin. No universal curing period applies; timing depends on the membrane system, film thickness and site conditions.

Comparing written scopes fairly

A useful tiling quote identifies preparation, tile format, layout, trims, grout, movement joints, access and waste. Where waterproofing or screeding is required, those items should be separately described so a finished-surface quote is not mistaken for a complete wet-area scope.

Licensing should be checked before acceptance. Waterproofing and tiling may sit within one coordinated scope where the contractor holds the appropriate South Australian authorisation for the work involved; ask for the licence scope and for any subcontracted work to be identified in writing.

Cost comparison is most useful when competing scopes describe the same room, the same assumed substrate, the same waterproofing boundaries and the same finish details. If one scope includes demolition, screed correction, waterproofing and waste while another lists only tiling labour, the totals are not comparable. Who this applies to

This applies to Adelaide owners planning a bathroom renovation, shower repair, ensuite update, laundry wet-zone finish or tiled floor and wall project where waterproofing, substrate condition and finish selection interact. It is also relevant when comparing a broader planning guide with a provider scope for the actual room.

Before demolition, record the existing room, suspected moisture, access limits, fixture changes and any hazardous-material questions that must be resolved by the responsible party. Before waterproofing, confirm substrate, falls, wastes, penetrations, thresholds and membrane system. Before tiling, set out tile modules, niches and trims so the visible finish does not hide unresolved wet-area risk.

  1. Record the room. Photograph the existing space, note moisture signs, dimensions, fixtures and access limits.
  2. Split the layers. Separate plumbing, substrate, waterproofing and tile finish so one trade is not assumed to cover every task.
  3. Demand written inclusions. List preparation, membrane work, screed to falls, trims, waste, cure timing and subcontracted items.
  4. Compare like scopes. Only compare totals where room, substrate assumptions, waterproofing boundaries and finish details match.

Common questions

Do tiles and grout make a shower waterproof? No. The waterproof layer is behind the finish, so membrane boundaries, penetrations, thresholds and cure sequencing should be confirmed before tiling begins.

Is there a universal curing period for bathroom waterproofing? No universal period is stated. Cure timing depends on the membrane system, film thickness and site conditions, so it should be confirmed in writing.

When are regrouting and surface repairs enough? They may suit maintenance issues, but a leak or failed shower finish needs diagnosis across sealant, plumbing, substrate movement and membrane assumptions before repair.
