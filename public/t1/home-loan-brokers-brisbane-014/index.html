Broker route or direct lender

A direct lender path may suit a borrower who already prefers one bank and is comfortable reading the product documents. A broker path is more useful when several lenders, a specialised loan type or a less straightforward borrower profile need to be compared.

ASIC Moneysmart home loan guidance tells borrowers to compare interest rates, costs and repayments. Use that as the baseline for any recommendation. The broker should explain more than a headline rate, including why certain lenders were ruled out and how the remaining options fit the borrower.

Questions that improve the recommendation

A useful broker conversation should produce a shortlist with reasons. Ask which lenders were considered, why some were excluded, what fees and features changed the ranking, and what assumptions were used for income, debts, rent, equity or construction costs.

Ask how the broker is paid. The source material states that the introduction is free to borrowers and says brokers are paid by lenders when a loan settles. That answer should still sit beside clear disclosure and a recommendation you can understand.

  1. Ask whether the broker has recent experience with your loan type.
  2. Ask which documents are needed before credit assessment.
  3. Ask what could slow approval or reduce borrowing capacity.
  4. Ask how redraw, offset, fixed, variable and repayment features are being weighed.
  5. Ask what happens if the preferred lender declines or changes conditions.
  1. Define the loan purpose. State whether the loan is for a first home, refinance, investment, construction, commercial need or vehicle before discussing lenders.
  2. Gather the inputs. Prepare income, debts, savings, equity position, property details and any existing loan information.
  3. Ask for the comparison logic. Request a clear explanation of lenders considered, fees, features, repayment options and reasons for the recommendation.
  4. Check authority guidance. Use ASIC Moneysmart home loan guidance to sense-check rate, cost and repayment comparisons before signing lender documents.

Common questions

Is a Brisbane broker useful for a first home buyer? It can be useful when the broker checks grant or scheme questions and compares limited deposit options against the borrower's actual savings and income. The source material specifically names first home buyer lending and Queensland grant guidance.

Does the stated service charge borrowers? The source material states there is no borrower cost and says brokers are paid by lenders when a loan settles. Ask the broker to explain commissions, fees and conflicts before proceeding.

What should a refinancer ask first? Start with the current rate, loan balance, fees, features and reason for switching. Then ask how a 100+ lender comparison changes the shortlist and whether any cashback offer improves the result after costs.

Can a broker help with construction lending? The source material names construction loans, new builds, knockdown rebuilds and progress payment lending. Ask how staged payments, builder documents and lender conditions will be managed for the project.
