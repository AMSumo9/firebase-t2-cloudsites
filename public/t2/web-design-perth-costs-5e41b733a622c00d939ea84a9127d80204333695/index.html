What a written quote should pin down

A tidy headline figure is not enough if two quotes assume completely different inputs. Ask each provider to respond to the same brief and the same inclusion checklist. If one quote includes content entry, image sourcing, technical setup and a training handover, while another excludes them, the cheaper number may only be cheaper on paper. Ask whether copywriting or content formatting is included. Check whether hosting, maintenance and support are part of the build or separate. Confirm whether basic search optimisation is included or priced separately. Request a staged scope so later additions do not turn into surprise invoices.

If those points matter to you, ask how they will be shown at sign-off, what training is included for simple edits, and what the care plan covers if you want ongoing updates, backups, security and support after launch.
